# Приглашение на свадьбу Юрия и Александры

Статический одностраничный сайт без сборщика и зависимостей.

## Просмотр

```bash
python3 -m http.server 8000
```

Откройте http://localhost:8000.

Страница построена одной вертикальной колонкой: приглашение, роспись в Грибоедовском ЗАГСе и празднование в Mascot Loft&Studio в 12:00. Для каждой локации предусмотрена отдельная кнопка карты.
