# Приглашение на свадьбу Юрия и Александры

Статический одностраничный сайт без сборщика и зависимостей.

## Просмотр

```bash
python3 -m http.server 8000
```

Откройте http://localhost:8000.

## Проверка

```bash
node --test tests/calendar.test.js
node --check script.js
```

Кнопка «Добавить в календарь» скачивает файл `.ics` с началом события 24 октября 2026 года в 09:00 по Москве (06:00 UTC). Страница построена одной вертикальной колонкой: приглашение, роспись в Грибоедовском ЗАГСе и празднование в Mascot Loft&Studio в 12:00. Для каждой локации предусмотрена отдельная кнопка карты.
